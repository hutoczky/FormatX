A nyers lemezfunkciók támogatott USB Mass Storage / SCSI Bulk-Only eszközön működésre készültek Android USB Host engedéllyel; a teljes fizikai eszközmátrix még nincs közzétéve.

VALÓS ANDROID-KORLÁT

Normál Android-alkalmazás nem kap nyers hozzáférést a telefon belső fizikai lemezéhez, rendszerpartícióihoz vagy SMART-parancsaihoz. Ezért a nyers lemezírás és törlés kizárólag támogatott külső OTG USB-tárolóra vonatkozhat.
