# FormatX real product screens

These assets are curated screenshots of the working Linux / Bazzite edition.

Included on the public homepage:

- Control Centre
- Live System Monitor
- Diagnostics
- Portable Installer
- USB Creator (empty state, waiting for ISO and target media)

The screenshots are stored as self-contained SVG wrappers with embedded WebP payloads. This keeps the release static, cacheable and compatible with the existing Content Security Policy.
